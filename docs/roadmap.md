# DAVEBOT Roadmap

## Phase 1 — Foundation

- Confirm requirements and terminology with toolmaking team.
- Implement baseline data model and seed data.
- Build quote calculator engine with configuration tables.
- Create basic quote PDF template with logo and company info.

## Phase 2 — WMS Workflow

- Job lifecycle views with status tracking.
- Routing steps and planned vs actual hours.
- Inventory management and BOM consumption.
- Reporting for job status and quote pipeline.

## Phase 3 — DAVEBOT Assistant

- Add DAVEBOT UI widget in the app.
- Implement calculation helpers (shot weight, cycle time, machine rate).
- Add FAQ knowledge base (terms, definitions, common troubleshooting).

## Phase 4 — Optimization

- Historical cost analysis with variance reporting.
- Automatic suggestions for quoting based on prior jobs.
- KPI dashboards (margin, utilization, lead time).
